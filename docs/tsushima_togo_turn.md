# 日本海海戦・東郷ターンの概念再現

1905年5月27日、日本側の記録時刻で **14:00〜14:20**。三笠を自艦とし、日本側12隻、ロシア側主力12隻の計24隻を1秒刻みで再生する。

**史料を参照した運動モデルであり、実測航跡の復元ではない。** 回頭・開戦の時刻と編成を軸に、未確定の位置・間隔・旋回運動を補間した初版。正確な戦闘詳報・原図の座標化は未実施で、特にロシア側の隊列合流と減速の再現が今後の課題となる。

## 再生

プロジェクトのルートで実行する。生成済みのタイムラインも同梱。

```powershell
python .\tools\build_tsushima.py
python .\tools\ais_scenario_player.py --timeline .\timeline\tsushima_togo_turn.jsonl --nmea-tcp-server 127.0.0.1:10110 --replay-speed 5
```

OpenCPN側は TCP、アドレス `127.0.0.1`、ポート `10110` の入力接続を設定する。接続設定後にプレイヤーを起動。サーバーは接続待ちで時刻を止めないため、途中から接続した場合はプレイヤーを終了して同じコマンドで再起動する。5倍速なら4分、20倍速なら1分。高倍率では受信側の表示更新が追いつかない場合があるので、最初は5倍速を使用する。

表示範囲の目安は北緯34.2〜34.4度、東経130.0〜130.2度。自艦＝三笠、`JP`＝日本側、`RU`＝ロシア側。AIS名は20文字以内の英字略称、日本語正式名はJSON内 `historical.display_name` に保存。AIS静的情報は開始時と60シナリオ秒ごとに出る。

ネットワークを使わない出力確認：

```powershell
python .\tools\ais_scenario_player.py --timeline .\timeline\tsushima_togo_turn.jsonl --dry-run --replay-speed 1000 > .\timeline\tsushima_togo_turn_preview.txt
```

シナリオJSONを直接編集した場合は通常のコンパイラーを使う。ビルダーを再実行すると、このシナリオと派生出力をビルダーの設定で上書きする。

```powershell
python .\tools\ais_scenario_compile.py --scenario .\scenarios\tsushima_togo_turn.json --output .\timeline\tsushima_togo_turn.jsonl --csv .\timeline\tsushima_togo_turn.csv
```

## 何を根拠にしたか

| 要素 | 採用内容 | 根拠・確度 |
|---|---|---|
| 日付と時刻 | 5月27日14:05 左回頭、14:10 日本側砲撃開始 | [アジア歴史資料センターの年表](https://www.jacar.go.jp/exhibition/nichiro2/sensoushi/kaijou_09_detail.html)。このモデルの基準 |
| 回頭方式 | 左への逐次回頭、第一戦隊の後に第二戦隊 | [東郷報告の英訳転載](https://losthistory.net/russojapanesewar/togo-aar3.html)、[参加者セミョーノフの記録](https://www.gutenberg.org/cache/epub/57324/pg57324-images.html) |
| 回頭後の方向・所要時間 | 東北東、三笠は約2分 | [豪州海軍歴史協会の記事](https://navyhistory.au/the-battle-of-tsushima-1905/)。後年の説明を参考にした採用値 |
| ロシア側の配置 | 右列4隻、左列8隻 | 東郷報告の観測像を簡略化。ロシア側の実際の隊列を確定したものではない |
| ロシア側開火 | 14:08 | 東郷報告の時刻を注記に採用。各国・各艦の時計を精密に同期させた時刻ではない |
| 編成と日本側順序 | 下記の主力艦 | [編成表](https://en.wikipedia.org/wiki/Battle_of_Tsushima_order_of_battle)と[戦闘概要](https://en.wikipedia.org/wiki/Battle_of_Tsushima)で照合した二次情報 |

参照日：2026-09-07。英訳転載は原本画像との逐語照合をしていない。Wikipediaの詳細年表にはアジ歴・東郷報告と異なる時刻や針路があるため、その年表全体は採用していない。艦名・編成の照合用途と区別した。

アジ歴の原史料候補は **C05110096300「第5号 日本海海戦第1合戦分図」** と **C05110096100「第3号 日本海海戦行動航跡図」**。今回は展示ページの解説と史料識別子まで確認し、原図画像を測量・トレースしたとは扱っていない。

## 艦隊

| 区分 | モデルの先頭からの順序 |
|---|---|
| 日本・第一戦隊 | 三笠 → 敷島 → 富士 → 朝日 → 春日 → 日進 |
| 日本・第二戦隊 | 出雲 → 吾妻 → 常磐 → 八雲 → 浅間 → 磐手 |
| ロシア・右列 | スヴォーロフ → アレクサンドルIII世 → ボロジノ → オリョール |
| ロシア・左列 | オスリャービャ → シソイ・ヴェリーキー → ナヴァリン → ナヒーモフ → ニコライI世 → アプラクシン → セニャーヴィン → ウシャコフ |

ロシア第三戦隊の末尾各艦のその瞬間の順序は一次史料未照合。編成表の列挙順を暫定採用した。巡洋艦の別部隊・駆逐艦・輸送船などは対象外で、両軍の全艦艇を収録したものではない。

## 推定値と省略

| パラメーター | 初版の値 | 意味 |
|---|---|---|
| 地図基準点 | 34.30°N, 130.10°E | 沖ノ島北方の表示用仮置き。三笠の回頭入口をローカル座標(0,0)に置く。史実の緯度経度ではない |
| 日本側針路 | 213.75° → 左へ146.25° → 67.5° | 南西微南から東北東への解釈。180°の半円には固定しない。全てモデル上の真方位、磁気偏差未補正 |
| 日本側速力 | 15 kn一定 | 代表値。旋回時の減速や個艦性能差を省略 |
| 三笠の回頭 | 14:05〜14:07 | 2秒ごとの針路イベントで一定角速度の旋回を近似。半径は約363 mと計算されるが、実測値ではない |
| 日本側艦間隔 | 中心間450 m、戦隊間900 m | 推定値。後続艦は距離÷速力の時間差で同じ航跡を追う |
| ロシア側速力 | 9 kn一定 | 代表値。初期観測の約12 knという東郷報告とも異なる。速力の時系列変化は未復元 |
| ロシア側針路 | 23° → 45° | 北北東寄りから北東への概念的な右変針。23°を当時の測定真針路として主張しない |
| ロシア側変針 | 先頭14:08〜14:11、後続は時間差 | 東向きに圧迫される運動の補間。開火と同時に変針したことを証明する値ではない |
| ロシア側列間隔 | 0.65 NM、左列先頭は0.25 NM後方 | 推定。整然とした二列に簡略化しており、隊列合流・オスリャービャの減速／停止を再現しない |
| 回頭開始時の旗艦間距離 | 8,000 m、三笠から方位168.75° | 幾何配置の採用値。資料には約7 kmなどの異なる値もあり、唯一の確定値としない |

「14:10に全艦の回頭が終わる」とはしていない。上記間隔では最後尾の磐手が回頭を終えるのは約14:18:40。これはモデルから算出された時刻で、実際の磐手の航海日誌の時刻ではない。

## 出力の解釈

- 砲撃開始はイベントCSVと航跡図の注記のみ。砲弾・命中・損害・沈没の計算はない。
- CPA/TCPAとsafe/caution/dangerは既存ツールによる現代的な衝突予測。砲撃の有効距離や戦術的優劣を示さない。近い艦隊間隔で警報が出ても、そのために航跡を変更していない。
- 当時AISは存在しない。MMSI・Class B・船種35は再生用の仮想情報。三笠は自艦NMEA、他23隻はAISとして出力する。
- NMEAの日時は既存プレイヤーの再生開始時刻を使う。1905年の日時をチャートプロッターへ送るものではない。歴史時刻は相対秒＋14:00として読み、1905年の日付は説明用メタデータに保持する。
- JSONの `historical` は説明用拡張で、既存コンパイラーは航跡に使わない。編成や注記を変えるときはビルダーと説明書も更新する。
- 会話内の航跡図は同じコンパイル結果の5秒サンプルを線形補間。実際のJSONLは1秒刻み。海岸線のない等縮尺の局所座標図で、実海図との位置合わせを保証しない。

## 検証と次の精度向上

`python -m pytest -q` で既存テストと追加テストを実行する。追加分は、逐次回頭が同じ空間軌跡を通ること、24隻・1,201時刻の出力、位置・針路の有限性、8 kmの初期幾何条件、開火時の概略距離帯、AISビット列の往復変換を確認する。これらは計算の整合性の検査で、史実の正確性を保証するものではない。

次段階では三笠・出雲の戦闘詳報と合戦分図を座標化し、ロシア側の艦長報告と時刻差を照合する。そこで初めて、海図上の基準点、各艦の遅れ、ロシア側隊列合流・速力変化をこの推定値から置き換える。

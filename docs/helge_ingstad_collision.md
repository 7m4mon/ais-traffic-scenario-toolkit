# Helge Ingstad / Sola TS 衝突・接近再現

**2018年11月8日 03:53:00〜04:01:15 CET（UTC+1）、8分15秒。**
HNoMS Helge Ingstadを自船、Sola TSをAIS相手船として再生する。
公式報告書にある針路・速力・時刻を基にした運動モデルであり、実測AISログの再生ではない。

## OpenCPNで再生

プロジェクトのルートで実行する。生成済みJSONLを同梱している。

```powershell
python .\tools\ais_scenario_player.py --timeline .\timeline\helge_ingstad_collision.jsonl --nmea-tcp-server 127.0.0.1:10110 --replay-speed 5
```

OpenCPNの入力接続をTCP `127.0.0.1:10110`に設定してから起動する。5倍速で1分39秒。
接続待ちで時刻は止まらないため、途中から接続した場合はプレイヤーを再起動する。
表示位置の目安は北緯60.62〜60.70度、東経4.83〜4.88度。
Helgeは自船RMC/GGA/HDT、SolaはAIS位置情報と船名として出力する。
NMEAの日時は再生時の現在日時。事故の現地時刻はイベントCSV・プレビューを使用する。

`timeline/helge_ingstad_collision_preview.html` をブラウザーで開くと、再生・一時停止・時刻スライダーが使える。
「接触付近を拡大」で最終接近を見られる。船型は寸法比に基づく概略図、点は船体中心。
海図・海岸線はない等縮尺の局所座標図。外部ライブラリーやネット接続は不要。

## 生成物と再生成

```powershell
python .\tools\build_helge_ingstad.py
```

- `scenarios/helge_ingstad_collision.json`：針路・速力の節点、出典、仮定、注記。
- `timeline/helge_ingstad_collision.jsonl`：1秒刻み、496時刻×2隻＝992レコード。
- `timeline/helge_ingstad_collision.csv`：同じデータのCSV。
- `timeline/helge_ingstad_collision_events.csv`：無線・操船指令などの出来事。
- `timeline/helge_ingstad_collision_range_checks.csv`：報告書の距離との比較。
- `timeline/helge_ingstad_collision_preview.html`：拡大・再生できる航跡図。

ビルダーの `build_scenario()` が入力の原本で、再実行すると上記JSONと出力を上書きする。
`kinematic_reconstruction/1` はこの専用ビルダーの形式。
**通常の `ais_scenario_compile.py` には渡さない。** COGと船首方位を分けて出力するために専用ビルダーを使用する。
既存シナリオ・プレイヤー・コンパイラーの動作は変更していない。

## モデルの作り方と仮定

1. 衝突概位（北緯60°38.5′・東経4°51.9′）を、仮の接触点に置く。
   Helge右舷の船体中心から後方20m・右方8.4mと、Solaの中心から前方120m・右方12mの仮の錨位置を一致させる。
   接触する場所の説明を参考にした**モデル上の寸法・位置仮定**であり、実物を測量した値ではない。
   表示点は船体中心なので、衝突時刻に2隻の表示点自体が重なるようにはしていない。
2. そこから針路・速力を1秒ごとの中間時刻で積分し、開始位置を逆算する。風・潮流・慣性を独立には計算しない。
   初期位置や途中の緯度経度は、この計算で生じるモデル値。実測位置として扱わない。
3. 節点の針路・速力を線形補間する。0°またぎの方位は最短方向で補間する。
   HelgeのCOGは船首方位で代用し、小さなふらつきを省略する。
4. Solaは04:00:20に報告された船首方位355°・COG345.8°・SOG7.2knを区別して使用する。
   それ以前のCOG345.8°一定は仮定。終端の船首方位000°、COG355°、7.0knも仮定。
   **000°への針路指令を、その瞬間に000°になったと解釈していない。**
5. 停止・全速後進は機関への指令として注記する。速力を直ちに0や負にしない。
   実際の減速曲線は取得しておらず、最後の速度変化はモデル値。
6. 全長はHelge 133.25m、Sola 249.9mを採用。描画用の幅16.8m／44mと船型・接触位置は概略。
   船体の掃引領域による厳密な最初の接触判定、錨や上部構造の立体形状、損傷・浸水は計算しない。
7. Tenax、Ajax、Dr. No、Silver Firda、Vestbris、Seigrunnの航跡は今回作らない。
   当時は他船もいたが、今回の2隻表示はその交通状況全体の復元ではない。
8. 無線は報告書の内容を日本語で要約した字幕。照明、見張り、錯覚、視認できる航海灯、音声は再現しない。
   地図上でSolaが見えることと、当時の乗員がタンカーと認識できたかは区別する。

## 距離の照合

報告書の距離は船首間距離。モデルも中心点から各船首位置へ移して比較した。
報告書本文と図の時刻に2〜5秒の違いがある箇所は、図の時刻を採用している。
これらの5点に合わせて途中位置を補正してはいない。

| 現地時刻 | 報告書 m | モデル m | モデル−報告書 m |
|---|---:|---:|---:|
| 03:57:27 | 2,720 | 2,664.93 | −55.07 |
| 03:59:07 | 1,510 | 1,463.38 | −46.62 |
| 03:59:57 | 875 | 852.57 | −22.43 |
| 04:00:27 | 500 | 485.15 | −14.85 |
| 04:00:47 | 250 | 243.78 | −6.22 |

この差は全航跡の位置誤差を示すものではない。数値の整合性の目安であり、実測の精度保証ではない。
終端接触は初めから与えた条件なので、接触したこと自体はモデルの正しさの検証にはならない。

## 出力・検証

`source=aibn_source_informed_model`。MMSI `999181101`／`999181102` は仮想値。
AISは再生用Class B形式。当時HelgeはAIS非送信だったため、本版では自船NMEAとして表示する。
CPA/TCPAはモデルのCOG/SOGによる等速直線予測で、船体間の最短距離や当時の装置表示ではない。

```powershell
python -m pytest -q tests
python .\tools\ais_scenario_player.py --timeline .\timeline\helge_ingstad_collision.jsonl --dry-run --replay-speed 10000 > $null
```

船首間距離の誤差範囲、方位の0°またぎ、機関指令後の移動、COGと船首方位の区別、生成データの一致、NMEA/AIS出力を確認する。
